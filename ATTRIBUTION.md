# Attribution and Source Boundaries

## Project identity

Letta Master Builder is an independent, unofficial community project by Ezra/Fimeg. It is not created, maintained, endorsed, certified, or production-accredited by Letta unless a future written statement from Letta explicitly says otherwise. The project must not imply affiliation through names, logos, presentation, or claims.

## Official sources and project facts

Official Letta documentation and released artifacts are authoritative for Letta product behavior. They must be cited as sources, with exact version, immutable reference, backend, topology, and retrieval or observation scope where relevant.

The following are **project facts**, not official Letta statements unless directly and accurately sourced:

- curriculum ordering and mandatory/elective choices;
- Agent Foundry conceptual architecture and autonomous-agent governance policies;
- authorization and fail-closed rules;
- claim labels, status vocabulary, rubrics, and publication gates;
- maintainer synthesis and production heuristics;
- work/improvement/supervisor loop design, assessments, evaluator procedures, and Runtime Validation plans.

A project choice informed by official documentation remains a project choice. Paraphrases must preserve limits and must not turn examples, documented possibilities, or exact-version observations into universal guarantees.

## Third-party material

Prefer links and concise quotations over reproducing source corpora. Preserve copyright, license, author, title, URL, and version notices required by each source. Do not use official Letta logos or imply endorsement. Code or text incorporated under another license must retain the applicable notice and be compatible with this repository's license.

## Validation claims

Static source review is not live validation. Assessment, independent evaluation, and runtime validation are distinct and separately authorized. Any future runtime claim must name its evidence scope; no such claim is made by this scaffold.

See `sources/UPDATE_POLICY.md` for review, correction, and freshness rules.
