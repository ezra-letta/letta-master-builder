# Formative Checkpoints

These fourteen module-specific companions provide non-awarding feedback during the read-only curriculum path. After each `modules/MOD-XX.md`, read the matching `assessments/formative/MOD-XX.md` before continuing.

Each checkpoint contains three must-pass learning invariants, a strong-versus-weak worked response, misconception indicators, a continue-or-revisit self-check, and the exact fields of the cumulative `dossier/template.yml` to inspect. A learner may record a private self-check later only under separate write authority. The repository pointer authorizes reading only.

Formative self-checks are not a scored assessment, independent evaluator evidence, learner credential, runtime observation, publication approval, or production qualification. `continue` means only that the reader can proceed to the next lesson without knowingly carrying the listed misconception.
